# Non-Goals

The canonical list lives in **`docs/ATLAS_MASTER_SPEC.md` §3** and is maintained there to avoid drift.

This file exists as a pointer because the scope boundary is something reviewers and judges should be
able to find without reading the full specification.

**Summary — ATLAS does not:** identify or score individual citizens as criminals · use protected
attributes · replace investigation or judicial process · assert legal chain of custody (it provides
tamper-*evidence*, which is weaker and honest) · connect to any real bank, NCRP, CFCFRMS or Samanvay
system in this repository · claim any certification or compliance it has not obtained · process real
PII or real transactions anywhere in this repository · perform general predictive policing.

ATLAS forecasts the **cash-out leg of reported financial fraud**. That is the whole claim.

Read §3 for the full statement and the reasoning behind each boundary.
